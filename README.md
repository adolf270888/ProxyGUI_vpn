# ProxyGUI Android VPN

## Что добавлено

Android `VpnService` + HevSocks5Tunnel 2.20.0. Kivy-интерфейс и существующий поиск SOCKS5 сохранены.

- Полный IPv4/IPv6 маршрут остальных приложений через TUN.
- DNS направляется в TUN через mapped DNS.
- При потере прокси движок останавливает передачу пакетов, VPN-интерфейс остаётся поднятым; прямого fallback для приложений в VPN нет.
- Когда ProxyGUI находит другой живой SOCKS5, движок запускается с новым endpoint.

**Важное исключение:** пакет самого ProxyGUI исключён из VPN, чтобы не зациклить соединение VPN-движка к SOCKS5-серверу. Поэтому сетевые запросы ProxyGUI и проверки доступности прокси идут напрямую. Остальные приложения Android направляются в VPN.

## Сборка APK

Сборка выполняется GitHub Actions workflow `.github/workflows/build.yml`:

1. Создайте GitHub-репозиторий и загрузите в него содержимое проекта.
2. Откройте вкладку **Actions** и запустите workflow **Build ProxyGUI VPN APK** (или отправьте push).
3. После успешной сборки скачайте artifact `proxygui-vpn-debug-apk`.
4. Внутри будет APK для установки на Android.

Workflow скачивает официальный `hev-socks5-tunnel.aar` версии 2.20.0 из релизов upstream и подключает его к Buildozer. Сторонний AAR не хранится в этом архиве.

## Первый запуск

1. Установите APK и откройте ProxyGUI.
2. Нажмите «Обновить и включить».
3. Подтвердите системный запрос Android на создание VPN-подключения.
4. Откройте «Настройки VPN» и включите для ProxyGUI «Всегда включённый VPN» и «Блокировать соединения без VPN», если эти параметры доступны на устройстве.
5. Проверьте доступ к сайтам и приложениям, затем отключите тестовый прокси или дождитесь его смены: трафик остальных приложений должен остановиться до восстановления туннеля.

## Проверки перед повседневным использованием

- Проверить IPv4 и IPv6 на утечки.
- Проверить DNS и UDP (не каждый публичный SOCKS5 поддерживает UDP ASSOCIATE).
- Проверить смену Wi-Fi ↔ мобильная сеть.
- Проверить блокировку трафика при остановке native engine, закрытии приложения и перезапуске Android.
- Проверить работу на конкретной прошивке Huawei/Android.

Текущая среда разработки не содержит Android SDK/Gradle/Buildozer, поэтому APK здесь не был собран и реальный тест на телефоне ещё не выполнен. Не используйте сборку для постоянной защиты данных, пока не пройдены проверки выше.
