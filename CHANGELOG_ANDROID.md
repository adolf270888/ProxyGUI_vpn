# ProxyGUI — изменения Android-версии

## Интеграция системного VPN (исходный код)

- Добавлен Android `VpnService` с foreground-уведомлением.
- Добавлен HevSocks5Tunnel 2.20.0 через официальный Android AAR и JNI API.
- TUN получает IPv4- и IPv6-маршруты по умолчанию; DNS направляется в туннель через mapped DNS.
- При потере SOCKS5 native tun2socks останавливается, а TUN-интерфейс остаётся поднятым. Пакеты остальных приложений не отправляются напрямую, пока мост ищет замену.
- При обнаружении нового рабочего SOCKS5 конфигурация движка обновляется автоматически.
- ProxyGUI исключён из собственного VPN-маршрута, чтобы соединение к upstream SOCKS5 не зацикливалось. Поэтому сетевые запросы самого ProxyGUI (включая проверку прокси) идут напрямую; остальные приложения устройства идут через VPN.
- Добавлен GitHub Actions workflow для скачивания официального AAR и сборки debug APK.

## Ограничения проверки

Исходный код интеграции добавлен, но APK в этой среде не собран: здесь нет Android SDK, Gradle и Buildozer. Поэтому нельзя считать интеграцию проверенной на устройстве до успешного CI build и теста на Android.

Для защиты при аварийном завершении VPN-службы рекомендуется после установки включить в системных настройках Android для ProxyGUI параметры «Всегда включённый VPN» и «Блокировать соединения без VPN» (названия могут отличаться у производителя).

## Предыдущий этап: локальный SOCKS-мост

- Проверка активного SOCKS5-апстрима выполняется каждые 10 секунд.
- При обнаружении отказа текущий апстрим немедленно сбрасывается.
- Пока рабочего сервера нет, новые подключения через локальный SOCKS-мост отклоняются; прямого fallback на обычное соединение в коде моста нет.
- Поиск нового SOCKS5 продолжается автоматически каждые 10 секунд, включая ситуацию, когда замена не найдена с первой попытки.
